# Mzansi Verified Services — Anti-Scam Local Directory CLI

A modular Python command-line application that helps users locate and verify local service providers (nail technicians, mechanics, hairdressers, etc.) across South Africa to protect against scams.

## 🚀 Features

- **Local Business Search**: Filter listings by location, service category, and official verification status.
- **Verification Engine**: Protects against service scams by checking CIPC / registration details.
- **Review System**: Allows users to leave verified ratings and comments for completed jobs.
- **Local JSON Storage**: Automatically loads and persists data to disk.

## 📁 Repository Structure

- `models.py`: Defines core data structures (`Business` and `Review`).
- `service_manager.py`: Handles database loading, saving, search filters, and business registration.
- `main.py`: Interactive CLI entry point for end-users.
